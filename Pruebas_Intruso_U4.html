¿Qué es una prueba de intrusión?

Pentesting = ciberataques controlados y autorizados contra servidores, redes, sitios web y aplicaciones, para descubrir lo que un atacante real podría explotar… y corregirlo antes de que lo haga.

Escaneo de vulnerabilidades
DETECTA

Automatizado: recorre el sistema y lista las debilidades que encuentra.

Pentest
EXPLOTA

Va más allá: explota las fallas de forma controlada para demostrar su impacto real en el negocio.

Hacking ético
CON PERMISO

El campo más amplio: cualquier uso de hacking para mejorar la seguridad, siempre con permiso explícito.

EN MÉXICO
Código Penal Federal

No define de forma específica el «delito informático» (queda a interpretación judicial), pero el acceso no autorizado a sistemas protegidos por un mecanismo de seguridad sí puede ser delito.

LFPDPPP

Sanciona el manejo indebido de datos personales: importa cuando, durante un pentest, se accede a información sensible.
